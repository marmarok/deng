# Karên Cotmehê: daneya vekirî · October jobs: open data

**Kurdî.** Koda karên Kaggle yên 18–22 Cotmeh 2026 ku tenê bi daneya vekirî dixebitin: arşîva Dengê Amerîka (malê giştî), Common Voice û FLEURS. Navên hesaban bûne `team/`.

- `k6-*`: kontrola zimên û kalîteyê ya beşên Dengê Amerîka
- `k7-redraft*`, `k7f-*`: nivîsandina reşnivîsan bi guhê me
- `k9-*`: guhê sêyem (Whisper-kmr)
- `k10-uc-kulak`: dengdana sê guhan; nivîs tê girtin heke du guh li hev bikin
- `ab1`, `ab2`: veqetandina axêveran û lîsteya beşên paqij ji bo deng
- `v1`, `d1`: beşên axaftinê ji bo ceribandinê
- `s13-utmos`: pîvana xwezayîbûna dengan
- `v3-acik-etiket`: nîşanên nû yên daneya vekirî ya Dengê Amerîka

**English.** Code of the Kaggle jobs from 18–22 October 2026 that use open data only: the Voice of America archive (public domain), Common Voice and FLEURS. Account names are replaced with `team/`. Each folder is one notebook; it reads its inputs from `/kaggle/input` and writes results to `/kaggle/working`.
